# AP-Chemistry-TI-84-Tools
This program can be used to calculate anything needed for AP Chemistry

The following can be calculated with this program:

Molar mass from a chemical formula
Grams ↔ moles
Percent composition
Empirical formula
Molecular formula
Stoichiometry
Limiting reactant
Theoretical yield
Percent yield
Moles ↔ particles using Avogadro’s number
Molarity
Dilution with \(M_1V_1=M_2V_2\)
Ideal gas law \(PV=nRT\)
Combined gas law
pH ↔ [H⁺]
pOH ↔ [OH⁻]
pH ↔ pOH
Ka ↔ pKa
Kb ↔ pKb
Ka ↔ Kb
Weak-acid pH
Weak-base pH
Buffers using Henderson–Hasselbalch
Reaction quotient \(Q\)
Compare Q vs K
Tell whether equilibrium shifts left/right
Calorimetry \(q=mc\Delta T\)
Gibbs free energy \(\Delta G=\Delta H-T\Delta S\)
Tell whether a process is spontaneous
Beer–Lambert law \(A=\varepsilon bc\)
Zero-order kinetics
First-order kinetics
Second-order kinetics
Half-life for zero, first, and second order
Nernst equation
\(\Delta G=-nFE\)
Find cell potential from \(\Delta G\)
Find \(E^\circ\) from \(K\)
Find \(K\) from \(E^\circ\)
Show common chemistry constants
